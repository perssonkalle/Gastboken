# Gästbok – C#

# Om uppgiften

Det är en enkel gästbok som är skapad i C# som en konsolapplikation. I applikationen så kan man lägga till nya inlägg, ta bort valfria inlägg samt visa alla inlägg som gjorts.

Alla inläggen sparas i en JSON-fil så dom finns kvar även när man startar programmet igen på nytt.

# Hur körs programmet?

1. Du kör applikationen igenom att öppna projektet i Visual Studio Code eller en terminal.
2. Öppna en ny terminal i projektmappen.
3. Kör "dotnet run" som kommando i terminalen.

Efter det så får du val om att skriva i gästboken eller om att ta bort inlägg.
Väljer du att du vill skriva i gästboken så får du skriva in ägare samt den text som du vill skriva.
När du är klar så har du ett alternativ för att avsluta programmet.
